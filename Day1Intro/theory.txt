Client-side code runs on the user's device.

Example:
JavaScript running in a web browser can respond to button clicks, validate
some form fields, and update the page without requesting a new page from
the server.

B. SERVER-SIDE
--------------

Server-side code runs on a server and commonly handles requests, applies
business rules, interacts with databases, and sends responses to clients.

Example:
Python code using Django, Flask, or FastAPI can run on a server to process
a user's login request.

Simple website example:

1. The user opens a website in a browser.
2. The browser sends a request to the server.
3. The server-side application processes the request.
4. The server sends a response.
5. The browser displays the response and runs any relevant client-side code.

Important:
- Running code in a terminal does not automatically make it server-side.
- Python can run locally on a laptop or on a remote server.
- JavaScript can run in a browser and also on a server using Node.js.
- A browser can display HTML and CSS while JavaScript handles client-side
  behavior.

What is Python??



Python is a high-level, general-purpose programming language known for its
readable syntax and broad range of applications.

---------------------------------------------------------------------------

Fetaures of python
1. High-Level Language
   Python provides abstractions that make code easier for humans to read
   and write.

2. Readable Syntax
   Python syntax is designed to be relatively clear and readable.

3. General-Purpose Language
   Python can be used in many different application areas.

4. Dynamically Typed
   Python determines and checks types at runtime. Variable names do not
   require fixed type declarations in the way they commonly do in Java.

   Example:

   num = 10
   num = "Hello"

   Here, the name num first refers to an integer object and later refers to
   a string object.

   More accurately, objects have types and names refer to objects.

5. Indentation-Based Blocks
   Python uses indentation to define blocks of code.

   Example:

   if 10 > 5:
       print("10 is greater than 5")

   The indented statement belongs to the if block.

   Python does not automatically insert indentation for every new block.
   Programmers must indent their code correctly. Four spaces per indentation
   level is the standard convention.

6. Cross-Platform
   Python is available on operating systems such as Windows, macOS, and Linux.

   Many Python programs can run on different operating systems if a compatible
   Python implementation and the required dependencies are available.

7. Multi-Paradigm
   Python supports procedural, object-oriented, and functional programming
   styles.

8. Large Standard Library and Ecosystem
   Python provides many built-in modules and has a large ecosystem of
   third-party packages.

9. Automatic Memory Management
   Python implementations manage memory for objects. Programmers usually do
   not manually allocate and free memory in the way they often do in C.

10. Scripting : Scripting Language

What is Scripting?

Scripting is the process of writing small or large programs to automate tasks,
control applications, process data, or connect different software components.

A scripting language is a programming language commonly used to write these
scripts.

Python is commonly used as a scripting language because it has readable
syntax, a large standard library, and supports rapid development.

Why do we need scripting?

Imagine that every day we need to:

Rename 100 files.

Read data from multiple text files.

Generate reports automatically.

Send automated notifications.

Check whether a particular file exists.

Perform repetitive tasks on a computer.

Instead of performing these tasks manually every day, we can write a Python
script to automate them.

PROGRAMMING PARADIGMS SUPPORTED BY PYTHON
--------------------------------------------

A programming paradigm is a style or approach to organizing and writing code.

A. Procedural Programming
   A program is organized around procedures and step-by-step instructions.

   Example:
   A function that calculates the total marks of a student.

B. Functional Programming
   Emphasizes functions, expressions, and reducing unintended side effects.

   Example:
   Using functions such as map() and filter(), or writing pure functions.

C. Object-Oriented Programming (OOP)
   Organizes code around objects that combine data and behavior.

   Example:
   A Student class with student details and methods.

D. Modular Programming
   Organizes code into separate, reusable modules.

   Example:
   Keeping calculation functions in calculations.py and importing them into
   another Python file.

Important:
Python supports multiple programming styles. Modular programming is mainly
an approach to organizing code rather than a separate core programming
paradigm.
