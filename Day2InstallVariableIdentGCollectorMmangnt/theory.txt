2. WHAT IS AN IDENTIFIER?

An identifier is a name used to identify a programming entity, such as a variable, function, class or module.

Example:

a = 10

Here, a is an identifier used as a variable name.

def test():
    print("Hello")

Here, test is an identifier used as a function name.

class Student:
    pass

Here, Student is an identifier used as a class name.

WHY DO WE USE IDENTIFIERS?

Identifiers help us give meaningful names to programming entities so that we can access and use them in our programs.

Example:

student_name = "XYZ"
student_age = 10

Here, student_name and student_age are meaningful identifiers.

--------------------------------------------------------------------------------

3. WHAT IS A VARIABLE?

A variable is a name that refers to an object.

For beginners, we can compare a variable to a labelled container. However, internally, Python variables work through name-to-object references rather than acting exactly like fixed storage boxes.

Example:

student_name = "XYZ"
age = 10
role = "developer"

Here:

student_name, age and role are variable names.

"XYZ", 10 and "developer" are values represented by Python objects.

We can check the type of an object using the type() function.

Example:

student_name = "XYZ"
age = 10
salary = 45000.50
is_trainer = True

print(type(student_name))
print(type(age))
print(type(salary))
print(type(is_trainer))

Output:

<class 'str'>
<class 'int'>
<class 'float'>
<class 'bool'>

WHY DO WE USE VARIABLES?

- To refer to data.
- To reuse data in a program.
- To perform calculations.
- To store references to objects.
- To make programs dynamic and maintainable.

Example:

price = 1000
quantity = 3

total = price * quantity

print(total)

Output:

3000

4. RULES FOR IDENTIFIERS / VARIABLE NAMES

Rule 1:
An identifier can start with a letter or an underscore.

Valid:
name = "Ravi"
_name = "Ravi"

Invalid:
1name = "Ravi"

Rule 2:
An identifier can contain letters, digits and underscores.

Valid:
student1 = "Ravi"
student_age = 20

Invalid:
student-age = 20

Rule 3:
Spaces are not allowed in identifiers.

Invalid:
student name = "Ravi"

Valid:
student_name = "Ravi"

Rule 4:
Hyphens and other unsupported special characters cannot be used in identifiers.

Invalid:
total-marks = 100
student@name = "Ravi"

Rule 5:
Python keywords cannot be used as ordinary identifiers.

Invalid:
class = "Python"

Valid:
class_name = "Python"

Rule 6:
Python identifiers are case-sensitive.

Example:

name = "Ravi"
Name = "Kiran"

print(name)
print(Name)

Output:

Ravi
Kiran

NOTE:
name and Name are two different identifiers.

BEST PRACTICE:

Use meaningful names.

Use snake_case for variables and functions.

Examples:

student_name
total_marks
calculate_salary()

5. RESERVED KEYWORDS

WHAT ARE RESERVED KEYWORDS?

Reserved keywords are words that have predefined syntactic meaning in Python. They cannot be used as ordinary identifiers.

Examples:

if
else
for
while
class
def
return
import
try
except
True
False
None

Example:

class = "Python"

This produces a SyntaxError because class is a reserved keyword.

Correct approach:

class_name = "Python"

HOW TO DISPLAY PYTHON KEYWORDS?

Example:

import keyword

print(keyword.kwlist)

The keyword module provides information about Python's reserved keywords.

To check whether a word is a keyword:

import keyword

print(keyword.iskeyword("class"))
print(keyword.iskeyword("student"))

Output:

True
False

6. MEMORY MANAGEMENT IN PYTHON

WHAT IS MEMORY MANAGEMENT?

Memory management is the process of allocating, using and reclaiming memory required by a program.

WHY IS MEMORY MANAGEMENT REQUIRED?

When we execute a program, Python objects require memory.

Examples:

- Integers
- Strings
- Lists
- Dictionaries
- Functions
- Objects created using classes

Python manages memory automatically in many common situations, reducing the need for programmers to manually allocate and free object memory.

HOW DOES PYTHON MANAGE MEMORY?

1. Python creates objects when needed.
2. Names and other objects can refer to those objects.
3. Python tracks references and object reachability.
4. Objects that are no longer needed can be reclaimed.
5. Python's memory allocator manages memory used by the interpreter.

NOTE:
Memory management and garbage collection are related, but they are not exactly the same.

Memory management is the broader process.

Garbage collection is one mechanism involved in reclaiming memory.

7. ID() FUNCTION — OBJECT IDENTITY

WHAT IS id()?

The id() function returns the identity of an object during its lifetime.

Example:

a = 10
name = "Python"

print(id(a))
print(id(name))

The output contains integer identity values.

ANALOGY:

id() is like an identity number assigned to an object.

However, in CPython, an object's identity is commonly associated with its memory address. Python does not guarantee that id() always returns a physical memory address.

IMPORTANT:
id() does not tell us how much memory an object occupies.

It identifies the object; it does not measure its size.

8. SIZE OF OBJECTS — SYS.GETSIZEOF()

WHAT DOES OBJECT SIZE MEAN?

Different Python objects can require different amounts of memory.

To check an object's size, we can use sys.getsizeof().

Example:

import sys

a = 10
name = "Python"
numbers = [10, 20, 30]

print(sys.getsizeof(a))
print(sys.getsizeof(name))
print(sys.getsizeof(numbers))

The output reports the size of each object in bytes.

ANALOGY:

id() = Object identity, like an identity number.

sys.getsizeof() = Approximate size of the object itself, measured in bytes.

IMPORTANT:

1. id() and sys.getsizeof() serve different purposes.
2. Object sizes depend on the Python implementation, version and platform.
3. sys.getsizeof() does not recursively count all objects referenced by a list or dictionary.
4. A variable name itself does not have a fixed size determined by the value assigned to it.

CORRECT SYNTAX:

sys.getsizeof(variable)

INCORRECT SYNTAX:

sys.sizeOf(variable)

Python is case-sensitive, so getsizeof must be written exactly as shown.

9. GARBAGE COLLECTION

WHAT IS GARBAGE COLLECTION?

Garbage collection is a process used to reclaim memory occupied by objects that are no longer needed.

HOW DOES PYTHON HANDLE IT?

In CPython, Python primarily uses reference counting, along with a cyclic garbage collector.

REFERENCE COUNTING:

Python tracks references to objects.

When an object's reference count reaches zero, CPython can generally deallocate that object immediately.

Example:

a = [10, 20, 30]
b = a

del a

print(b)

Output:

[10, 20, 30]

Explanation:

Both a and b initially refer to the same list object.

When we delete a, the name a is removed.

The object still exists because b refers to it.

Therefore, del does not always destroy an object.

CYCLIC GARBAGE COLLECTION:

Sometimes objects refer to one another in a cycle, even when the cycle is no longer reachable from the rest of the program.

The cyclic garbage collector can identify and reclaim certain such objects.

Example:

import gc

print(gc.isenabled())

collected = gc.collect()

print("Objects collected:", collected)

The gc module provides functions for working with Python's cyclic garbage collector.

NOTE:
gc.collect() requests a collection pass. It does not mean that every unused object in memory will necessarily be collected by that call.
